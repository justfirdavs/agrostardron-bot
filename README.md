# АгроСтарДрон — Telegram-бот учёта дронов

Бот для учёта парка дронов, команд, батарей, генераторов и автомобилей, а
также для приёма полевых отчётов (текст + фото/видео) от пилотов.

## Что уже внутри

- Из вашего файла `Дрон свод.xlsx` загружены только достоверные данные:
  17 дронов (серийный номер, модель, налёт) и коды команд (A, B, C, D, G, H).
  Это лежит в `data/seed_data.json` и попадает в базу при первом запуске.
- Серийные номера батарей/генератора, показания и данные автомобиля,
  а также состав команд **специально не подставлены** — в вашей исходной
  таблице это были условные значения для примера. В боте их вводит сам
  руководитель команды (см. ниже).
- Роли: **администратор** (видит и назначает всё), **руководитель команды**
  (вносит данные генератора/батарей/авто своего дрона, видит и отчитывается
  по своим дронам) и **пилот** (видит свои дроны, отправляет отчёты).
- Карточка дрона: модель, налёт, состав команды, все батареи со статусом
  (Норма / Скоро замена / Заменить), генератор со статусом замены масла,
  автомобиль со статусом замены масла, история ремонтов.
- Кнопки обновления показаний (налёт, циклы батарей, моточасы генератора,
  пробег авто) — чтобы статусы оставались актуальными.
- Приём отчётов от команд: вид работ, поле/локация, площадь, комментарий,
  фото и видео. Администратору сразу приходит уведомление с медиа.
- Просмотр истории отчётов (у команды — свои, у администратора — все).

## Как это работает на практике

1. **Вы (админ)** нажимаете /start первым — становитесь администратором.
2. В разделе **🚁 Дроны** открываете нужный дрон и жмёте
   **👥 Назначить команду** — выбираете, какой команде (A, B, C…) он
   принадлежит.
3. Даёте руководителю команды код (например, `A`) и просите его нажать
   **/start** в боте.
4. Руководитель вводит код, отвечает «Я руководитель команды» — и бот
   сразу пошагово спрашивает: серийный номер и моточасы генератора,
   серийные номера и циклы всех 3 батарей, марку/номер/VIN/пробег
   автомобиля. Всё это сохраняется в карточку дрона.
5. Остальные пилоты команды нажимают /start, вводят тот же код и отвечают
   «Я пилот» — видят дрон и могут отправлять отчёты, но не могут менять
   данные техники (это может только руководитель).
6. Если у команды несколько дронов — руководитель заполняет данные по
   каждому через кнопку **⚙️ Данные дрона** в меню (можно и позже
   отредактировать, если что-то поменялось).

## Шаг 1. Разверните бота на Railway (бесплатно/недорого)

1. Зайдите на **railway.app** и войдите через GitHub (или создайте аккаунт).
2. Нажмите **New Project → Deploy from GitHub repo**. Если проекта нет на
   GitHub — сначала загрузите папку с кодом в новый репозиторий на
   **github.com** (кнопка "Add file → Upload files", перетащите все файлы).
3. Выберите этот репозиторий для деплоя.
4. Railway сам увидит `requirements.txt` и `Procfile` и соберёт проект.
5. Откройте вкладку **Variables** и добавьте:
   - `BOT_TOKEN` — токен вашего бота от @BotFather.
   - `DB_PATH` — впишите `/data/bot.db`
6. Добавьте постоянный диск, чтобы данные не терялись при обновлениях:
   вкладка **Settings → Volumes → New Volume**, точка монтирования `/data`.
7. Нажмите **Deploy**. Через минуту бот будет работать 24/7.

## Шаг 2. Станьте администратором

Просто откройте вашего бота в Telegram и нажмите **/start**. Самый первый
человек, который это сделает, автоматически становится администратором.
Поэтому сделайте это вы, раньше остальных.

Если нужно назначить ещё одного администратора — попросите его сначала
нажать /start в боте (он станет "командой" по умолчанию), узнайте его
Telegram ID через бота **@userinfobot**, и отправьте в чат с ботом команду:

```
/promote 123456789
```

## Шаг 3. Назначьте дроны командам и раздайте коды

У каждой команды есть буквенный код (A, B, C, D, G, H — как в вашей
таблице). Сначала вы (в разделе **🚁 Дроны**) назначаете, какой дрон за
какой командой закреплён. Затем даёте руководителю команды его код —
он вводит его в боте при /start, отвечает «Я руководитель команды», и
бот сам проведёт его через ввод генератора, батарей и авто. Пилотам той
же команды даёте тот же код — они отвечают «Я пилот».

Посмотреть коды и состав команд можно в разделе **👥 Команды** (доступно
администратору).

## Важные заметки по данным

- Дроны (17 штук) и их серийные номера, модель и налёт — взяты из вашей
  таблицы как есть, это подтверждённые данные.
- Все остальное (какой дрон за какой командой, серийники батарей/
  генератора, данные авто, состав команд) в исходном файле были условными
  примерами — поэтому в боте это поле пустое, пока админ и руководители
  не введут его сами (см. «Как это работает на практике» выше).

## Локальный запуск (для разработчика)

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # впишите туда BOT_TOKEN
python bot.py
```

## Структура проекта

```
bot.py              — точка входа, запуск polling
config.py           — переменные окружения и настройки
db.py                — схема БД, сидинг из data/seed_data.json, все запросы
utils.py             — расчёт статусов износа (батареи/масло)
keyboards.py         — все inline/reply клавиатуры
states.py            — состояния FSM (диалоги)
handlers/start.py     — /start, регистрация (лидер/пилот), /promote
handlers/equipment.py — мастер ввода генератора/батарей/авто (для лидера)
handlers/drones.py    — список дронов и карточка дрона
handlers/teams.py     — команды, назначение дрон↔команда, свод по парку
handlers/updates.py   — обновление показаний (админ)
handlers/reports.py   — отправка и просмотр отчётов
data/seed_data.json  — данные, извлечённые из Дрон свод.xlsx
```
